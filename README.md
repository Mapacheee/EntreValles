# EntreValles

```sh
npm install
npm run dev
```

| Comando | Función |
| --- | --- |
| `npm run dev` | Inicia el servidor de desarrollo. |
| `npm run build` | Comprueba TypeScript y genera la aplicación en `dist/`. |
| `npm run preview` | Permite revisar localmente la compilación generada. Ejecuta `build` antes. |
| `npm test` | Ejecuta las pruebas de restauración del progreso y acciones del recorrido con `node:test`. |
| `npm run lint` | Revisa el código con Oxlint. |
